LAGOS Backup

Privacy Policy · last updated 20 November 2026

LAGOS Backup is a private tool used only by the owner of LAGOS PlayStation to store backup copies of its own billing database in the owner's own Google Drive account. It is not offered to the public.

What data is accessed

The app requests only the drive.file permission. With this permission it can create, read, update and delete only the backup files that it created itself in the owner's Google Drive. It cannot see or access any other files in the Drive.

How data is used

The app uploads compressed backup copies of the LAGOS billing database to a folder named "LAGOS-cadangan" in the owner's Google Drive, and removes old backups that it created. The data is used only for backup and restore by the owner.

Sharing

No data is sold, shared with, or transferred to any third party. Backups stay in the owner's own Google Drive account.

Storage and security

The access token is stored only on the owner's own LAGOS server and is never published. The owner can revoke access at any time from the Google Account security settings.

Kebijakan Privasi · diperbarui 20 November 2026

LAGOS Backup adalah alat pribadi milik pemilik LAGOS PlayStation untuk menyimpan cadangan database billing miliknya sendiri ke akun Google Drive miliknya sendiri. Aplikasi ini tidak ditawarkan untuk umum.

Aplikasi hanya memakai izin drive.file: hanya bisa membuat, membaca, mengubah, dan menghapus file cadangan buatannya sendiri. File lain di Google Drive tidak bisa diakses. Data tidak dijual atau dibagikan ke pihak mana pun, dan izin dapat dicabut kapan saja dari pengaturan keamanan Akun Google.
